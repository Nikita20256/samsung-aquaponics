# app

Приложение React Native с Expo и TypeScript, подключённое к серверу Aquaponics.
Стартовый экран Fish & Greens:
фон с тропической листвой, название, вращающаяся композиция с рыбками
и надпись «Загрузка» с пульсирующими точками. Через 3 секунды открывается вход;
после успешной авторизации — главная страница. При сохранённой сессии открывается
сразу главный экран с показателями, стеклянными карточками и овальной навигацией.
Используется системный шрифт без загрузки дополнительных ресурсов.

## Обновление до Expo SDK 58 — 25 октября 2026

Проект переведён на Expo `58.0.19`, React Native `0.88.0` и React `19.3.0`.
Версии `expo-blur`, `expo-constants`, `expo-secure-store`, safe-area-context,
SVG, web и типов React согласованы с SDK 58. `package-lock.json` обновлён.
Ссылки на нативные компоненты используют `ViewInstance` / `TextInputInstance`;
отсутствующая стартовая ссылка обрабатывается как `null`.

В SDK 58 обычный `--tunnel` использует новый сервис Expo с авторизацией.
Команда `npm run start:tunnel` и скрипт `mobile:tunnel` явно выбирают
`--tunnel ngrok`, сохраняя существующее подключение без входа в аккаунт Expo.
Основание: [заметки SDK 58](https://expo.dev/changelog/sdk-58) и
[инструкция обновления](https://docs.expo.dev/workflow/upgrading-expo-sdk-walkthrough/).

Проверки: TypeScript; восемь тестов API; `expo install --check`;
Expo Doctor `20/20`; экспорт бандлов Android/iOS/web с Hermes для мобильных платформ.
При запуске через ngrok публичный Android-манифест сообщает `sdkVersion: 58.0.0`,
бандл успешно загружается; сервер отвечает через HTTPS, а JWT и ключ подключения
остаются обязательными. В браузере экран входа, фон и три иконки загружаются без
ошибок и предупреждений в консоли.
Это проверка бандлов, не выпуск APK/IPA. Проверка на физическом телефоне отдельно
не выполнена. Для Expo Go нужна версия с поддержкой SDK 58.

`npm audit` сообщает о 7 замечаниях в зависимостях Expo CLI/ngrok
(2 moderate, 5 high: цепочки node-forge, zod и uuid). Они не устранялись
принудительной заменой: предложенный npm вариант включает несовместимый откат
Expo до SDK 44. `npm audit fix --force` не применялся.
Резервные копии конфигурации и изменённых исходников до миграции находятся
в игнорируемой папке `.expo/sdk57-before-upgrade/`.

## Сервер и мобильное приложение — 22 октября 2026

Мобильный клиент находится в этой папке `app`. Сервер остаётся отдельно:
`../backend`, его стек запускается из
`..` командой `docker compose up -d`.
Сайт и мобильное приложение используют одну базу, пользователей и устройства.

После загрузочного экрана открывается вход. Реализованы:

- вход, регистрация, подтверждение почты и восстановление пароля;
- сохранение JWT на Android/iOS через `expo-secure-store`, выход при истечении токена;
- список и выбор установок, привязка по ID и секретному коду;
- реальные показания, статус связи, время последней связи и счётчик включений;
- режимы света и аэрации `off / auto / on` через сервер;
- история влажности, температуры и света за сутки / неделю;
- профиль, смена пароля, подтверждение новой почты, часовой пояс;
- почтовые оповещения, интервалы и пороги датчиков для выбранной установки.

Случайные показания на главном экране отключены. До получения данных показывается
«—» / «Нет данных». Серверный датчик воды бинарный: «В норме» / «Мало воды»;
процент воды из него не вычисляется. Последние значения устройства вне сети
сопровождаются временем связи. Минимум/максимум температуры относятся к текущему
сеансу выбранной установки, история — к сохранённым сервером данным.

Опрос выполняется раз в 10 секунд без наложения запросов, останавливается в фоне
и возобновляется при возврате. Ответы для предыдущей установки отбрасываются.
Переключатели недоступны без актуального соединения и статуса устройства «В сети».
Ответ API означает принятие команды сервером: подтверждения исполнения от
контроллера существующий сервер не предоставляет.

### Адрес API

На экране входа можно изменить адрес, например `http://192.168.1.10:3000/api`.
Адрес сохраняется вместе с успешным входом. Пароли БД, JWT-секрет сервера
и MQTT-пароль в мобильное приложение не переносятся.

Порядок выбора начального адреса:

1. `EXPO_PUBLIC_API_URL` в `.env.local`, если значение задано.
2. Для web — имя компьютера из адресной строки и порт `3000`.
3. Для Expo Go в локальной сети — адрес компьютера из конфигурации Expo.
4. Резервный адрес: Android-эмулятор `http://10.0.2.2:3000/api`, iOS — `http://localhost:3000/api`.

Для фиксированного сервера скопируйте `.env.example` в `.env.local` и укажите URL.
Это публичная переменная Expo; секреты в неё помещать нельзя.
После изменения перезагрузите приложение.

Телефон и компьютер должны иметь сетевой доступ друг к другу. `localhost` на
физическом телефоне указывает на телефон. При использовании VPN может понадобиться
разрешить доступ к локальной сети в настройках VPN. Туннель `expo start --tunnel`
передаёт Metro, но сам по себе не открывает API сервера. Для удалённого сервера
и собственной нативной сборки используйте HTTPS.

Для Expo web добавьте его origin, например `http://localhost:8081`, в
`CORS_ORIGINS` файла `../.env`, затем выполните
`docker compose up -d --no-deps backend` из папки сервера. На этом компьютере
локальные origin Expo уже добавлены. Нативный клиент не требует браузерного CORS.
В локальном стеке письма находятся в Mailpit: `http://localhost:8025`.

### Android через VPN: туннель с доступом к API

Для запуска на физическом Android при включённом VPN:

1. Установите [Expo Go для SDK 58](https://expo.dev/go?sdkVersion=58&platform=android&device=true).
2. При работающем локальном Docker-стеке выполните `npm run mobile:tunnel` в `app`.
3. После строки `Tunnel ready` в другом терминале из `app` выполните `npm run mobile:qr`.
4. Отсканируйте `../mobile-access/android-qr.png` сканером Expo Go.

Туннель передаёт отладочную сборку и API через Expo/ngrok. VPN и системные правила
Docker не изменяются. Дополнительный ключ доступа содержится только в личном QR
и хранилище сессии телефона; в публичную JavaScript-сборку он не включается.
`/api` на сервере Expo передаётся только на `127.0.0.1:3000` и требует этот ключ.
Авторизация JWT локального API продолжает действовать. Адрес API подставляется
из ссылки QR. При перезапуске туннеля отсканируйте новый QR-код.

Файлы доступа сохраняются рядом с `app`, вне каталога Metro. Не публикуйте QR
или `mobile-access` в репозиторий. Обычный `npm run start:tunnel` запускает только
Expo; для приложения вместе с API используйте `npm run mobile:tunnel`.

## Экран Fish & Greens

В `assets/loading/fish-loading.svg` находится предоставленный пользователем
экспорт группы из Figma, скопированный без изменений. SVG имеет размеры
328 × 367 и содержит рыбок со встроенным PNG, пузырьки, дуги и фильтры свечения.
Загрузка ресурсов из Figma или интернета при запуске приложения не нужна.

`FishLoadingIndicator` принимает текст SVG через `xml`, размер в логических
пикселях через `size` и длительность оборота через `durationMs`
(по умолчанию 4000 мс). Размеры исходного SVG сохраняются: масштабируется
центрированная обёртка. При замене файла с другими размерами также измените
`artworkWidth` и `artworkHeight`. Вся композиция вращается по часовой стрелке
единым блоком; надписи остаются неподвижными.

Фоновое изображение заполняет весь экран с сохранением пропорций (`cover`),
при необходимости края обрезаются. Фон плавно увеличивается от 100% до 108%
и уменьшается обратно за 10 секунд. Изображение включено в приложение и доступно без интернета.

На Android и iOS вращение выполняется нативным драйвером и останавливается
при сворачивании приложения. Системная настройка уменьшения движения
отключает вращение, пульсацию точек и масштабирование фона. Экран учитывает безопасные отступы и доступную высоту.

Для SVG используются `react-native-svg` и небольшой Metro-трансформер,
который импортирует исходный XML без оптимизации или перерисовки.
`react-native-safe-area-context` защищает содержимое от вырезов экрана.
Экран загрузки не обращается к серверу. После 3000 мс с момента монтирования приложения
и восстановления сессии открывается авторизация или главная страница. Таймер учитывает прошедшее время при возврате
из фона и очищается при размонтировании. После перехода анимации загрузки
размонтируются. Длительность задаётся в `src/config/startup.ts`.

## Главная страница — 19 октября 2026

Главный экран использует предоставленный фон `assets/home/background.png`.
Изображение заполняет весь экран с сохранением пропорций (`cover`) под карточками и навигацией.

Реализована из сохранённого исходника дизайна с согласованными последними правками:
влажность почвы слева, температура среды справа, без строки истории и метки «Демо»,
с овальной навигацией. Основные элементы — нативные View, Text и Pressable.
Стекло использует `expo-blur` и полупрозрачные SVG-градиенты, блики и контуры.
Фон для стекла размещён в `BlurTargetView`.
Настройки прозрачных карточек собраны в `src/theme/glass.ts`: свет 135° / 32%,
интенсивность размытия 12 (2,4 px на web) и тонкий контур 1 px.
Листья просвечивают через лёгкую тёмную заливку, широкий внутренний ободок убран.
Внутри карточек датчиков движутся три мягких цветных пятна — зелёное, бирюзовое
и светло-оливковое. Полный проход занимает 14–17 секунд, траектории различаются
между плашками. Слой расположен под текстом, обрезается по скруглениям и не
перехватывает нажатия. Движение приостанавливается в фоне и отключается при
системной настройке уменьшения движения. В нижней навигации цветовых переливов нет.
Фон пользователя `assets/home/background.png` сохранён.
Иконки скопированы из исходника без изменений, резервуар перенесён из того же SVG.
Системная строка состояния остаётся настоящей — её изображение из макета не копируется.

По просьбе пользователя возвращена компоновка до изменений адаптивности.
Приложение открывается в портретной ориентации. Ширина страницы ограничена
480 логическими пикселями, размеры и отступы карточек постоянные.
Если содержимое вместе с шапкой не помещается по высоте, оно пропорционально
уменьшается; навигация остаётся снизу с отступом 24 пикселя. Прокрутки нет.
Переключатели снова компактные, с минимальным размером кнопки 45 × 32.
Экран загрузки и информационные окна также возвращены к прежней компоновке.

С 22 октября показания, режимы и разделы подключены к серверу, как описано выше.
Полоса света использует шкалу 0–2000 лк. Декоративная анимация воды
приостанавливается в фоне и учитывает системное уменьшение движения.

Проверено: TypeScript, сборка Android/iOS/web, граница перехода 2999/3000 мс,

## Требования

- Node.js, соответствующий `^22.13.0 || ^24.3.0 || ^26.0.0 || >=27.0.0`; рекомендуется Node.js 24 LTS.
- npm.
- Для просмотра на телефоне — Expo Go, совместимый с Expo SDK 58. Версии Expo Go доступны на https://expo.dev/go. При обычном запуске телефон и компьютер должны быть в одной сети; при запуске через туннель достаточно доступа к интернету на обоих устройствах.
- Для запуска Android-эмулятора — настроенный Android SDK и созданное виртуальное устройство.

Проект использует Expo SDK 58, React 19.3.0 и React Native 0.88.0. Для первой установки зависимостей нужен доступ к npm.

## Запуск

Откройте терминал в папке проекта:

```powershell
npm ci
npm start
```

Если `node_modules` уже установлен, можно сразу выполнить `npm start`.

### Запуск при включённом VPN

Если телефон не может подключиться к компьютеру по локальной сети, остановите сервер через Ctrl+C и запустите туннель:

```powershell
npm run start:tunnel
```

Пакет `@expo/ngrok` установлен как зависимость разработки проекта, поэтому глобальная установка не требуется. После `npm ci` он устанавливается автоматически. Дождитесь нового QR-кода и отсканируйте его в Expo Go. Туннель работает через интернет, поэтому VPN можно оставить включённым, если он разрешает доступ к сервису туннеля. Загрузка может быть медленнее, чем по локальной сети.

Если появляется `CommandError: Install @expo/ngrok@^4.1.0 and try again`, выполните `npm ci` и повторите запуск. Глобально установленный пакет может не обнаруживаться Expo CLI; локальная зависимость устраняет эту причину ошибки.

Сообщение `Project is incompatible with this version of Expo Go` означает несовпадение SDK. Для этого проекта нужен Expo Go для SDK 58.

### Эмуляторы

Для запуска на настроенном Android-эмуляторе:

```powershell
npm run android
```

На macOS с установленным Xcode можно использовать `npm run ios`. Запуск iOS-симулятора на Windows не поддерживается.
